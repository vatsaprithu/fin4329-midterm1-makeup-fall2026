# FIN 4329 Midterm Exam 1 make-up (Fall 2026)

Make-up exam page for FIN 4329 Bank Lending, Friday, October 30, 2026 (Mountain Time).

- `index.html`: the exam. Questions are encrypted (AES-256-GCM, key derived from the access code with PBKDF2-SHA256) and cannot be read without the code given at the start.
- `FIN4329_MT1_Makeup_SetupCheck.seb`: opens this page in Safe Exam Browser to confirm the setup before the exam.
- `FIN4329_MT1_Makeup_Exam.seb`: the Safe Exam Browser configuration used for the exam.

Student data stays in the student's own browser until the student downloads the exam file and uploads it to Blackboard. Nothing is sent to any other service.
